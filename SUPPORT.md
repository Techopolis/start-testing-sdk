# Getting help

1. Read the README, then the guide for your platform in `docs/`.
2. Run the tests for your platform (`swift test --package-path apple`) to see
   whether the SDK itself works on your machine.
3. Still stuck? Open an issue with the bug report template.

Questions about the Start Testing service, such as your account, projects, or
SDK keys, belong with [Start Testing](https://starttesting.net), not this
repository.

For security problems, see [SECURITY.md](SECURITY.md) instead of opening an
issue.
